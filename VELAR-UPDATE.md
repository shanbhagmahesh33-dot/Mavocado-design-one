## Publish to the existing GitHub Pages website

1. Extract `Mavocado-VELAR-GitHub-Update.zip`.
2. Copy its contents into the root of `Mavocado-design-one`, preserving the `assets/work/velar/` and `projects/velar/` folders. Overwrite the included `index.html`, `work.html` and `sitemap.xml`.
3. Commit the files to the branch already serving GitHub Pages (main / root).
4. Wait for the existing Pages deployment to finish. VELAR will be at `/velar.html`; its live demo will be at `/projects/velar/index.html`.

No build step is required. This is an update package and relies on the existing website's shared CSS, scripts and assets. Keep the current CNAME, DNS settings and existing website files.

## Scope of the VELAR demo

VELAR is an independent concept. Rates and pickup areas are illustrative. The booking flow calculates a preview, stores it in the browser and offers a text download. It does not take payment, send booking information, reserve inventory or confirm a rental.
