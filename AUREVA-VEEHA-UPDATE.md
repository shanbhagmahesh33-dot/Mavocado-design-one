# Auréva and Veeha Studio portfolio update

Copy the contents of this ZIP into the root of `shanbhagmahesh33-dot/Mavocado-design-one` on the branch that serves mavocado.design. The ZIP uses the repository root layout and needs no build step.

1. Open the current main branch and extract this ZIP. Keep the folder paths as shown.
2. Copy the files into the repository. Merge `index.html`, `work.html`, and `sitemap.xml` if those files have changed since the versions listed below.
3. Commit the update and publish it via the existing GitHub Pages workflow.

The homepage gallery and Selected Work place Auréva and Veeha Studio first, in that order. Both are also listed under Websites on the Work page. Each case study includes six actual UI shots in Bluehour’s cobalt MacBook mockup on its existing lime-green background. The **Explore Live** buttons open the bundled demos at `projects/aureva/` and `projects/veeha-studio/`.

The demos prepare enquiries in the browser. They do not send messages or confirm appointments. The Veeha offer and testimonials are sample content.
