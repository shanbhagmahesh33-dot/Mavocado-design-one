# Veyra Works

A complete responsive manufacturing website design study by Mavocado. Open index.html or upload the root contents of the ZIP to GitHub Pages. No build step is required.

Includes original vector branding, Chivo and Martian Mono fonts with OFL licenses, six coordinated generated images, capability tabs, component filters and detail panels, scroll-driven form study, keyboard navigation and reduced-motion support.

The enquiry form prepares a local TXT brief. It does not send personal details, upload drawing files or submit an RFQ. File names are listed for reference only. Connect an approved backend before collecting real enquiries.

Veyra Works is fictional. Imagery is generated; numerical specifications, certifications, customer testimonials and business results are not claimed. The drawing reveal is a visual form study, not a production drawing.

Motion reference recordings were not accessible in this request. The implemented motion is original and can be matched to supplied recordings later.
