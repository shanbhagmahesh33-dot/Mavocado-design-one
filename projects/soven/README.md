# SOVEN — Interior Studio Website

An original responsive HTML/CSS/JavaScript design inspired by the supplied hero, horizontal services and floating testimonial motion references.

## Open the design
Open index.html directly in a modern browser. No build tool, package installation or server is required. Keep assets, styles.css and script.js beside index.html. Alternatively serve this folder using any static hosting service, including GitHub Pages.

The separate Soven-Interiors.html download embeds all images, fonts, styles and scripts, and can be opened on its own.

## Included interactions
- Full-screen, crossfading three-image hero with pause and image selection.
- Native menu dialog with keyboard focus handling and Escape support.
- Six animated studio metrics, with no partner logos.
- Project category filters and project detail dialogs.
- Scroll-driven horizontal services on desktop; swipeable panels on mobile.
- Service detail dialogs and project-type selection carried into the enquiry form.
- Pinned, floating client-story section.
- Native accessible FAQ and process accordions.
- Required-field form validation and local text-file enquiry download.
- Reduced-motion alternatives, responsive typography and layouts.

## What is a concept
SOVEN is a fictional studio. Names, metrics, projects and testimonials are illustrative, explicitly labelled in the page. Interior images were generated for this concept and are not photographs of completed client projects. Replace these with approved business details and real client permissions before commercial publication.

## Form delivery
This is a front-end design. The form creates a local .txt file; it does not email, store, or submit details. Production email/CRM delivery requires a server-side or hosted form integration, spam controls and a privacy policy. No secrets belong in browser JavaScript.

## Files
- index.html: page structure and content
- styles.css: visual system, responsive layout and motion alternatives
- script.js: UI interactions, scroll motion and local enquiry export
- assets/: six WebP interior images, two Inter Tight fonts, font licence and favicon
- IMAGE-DIRECTION.json: image creation directions
- VALIDATION.md: checks performed

Inter Tight is bundled under the accompanying SIL Open Font License. No external font or animation library is needed.
