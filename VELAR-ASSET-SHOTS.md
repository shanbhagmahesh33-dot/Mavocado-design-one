# VELAR image production

Created with the built-in image generation tool using the existing Fieldwork silver MacBook reference plus screenshots captured from the recovered VELAR source. Project assets are 1536 × 1024 WebP files under `assets/work/velar/`.

Prompt direction: compositing only. Retain the identical front-facing silver MacBook, notched black bezel, keyboard, silver base, soft shadow, vivid Mavocado blue #080ed2 background and generous margins from the Fieldwork reference. Replace only the display with the supplied VELAR screenshot, fitting its actual layout and keeping the entire laptop visible. Do not redesign the UI, invent interface text, crop the device, add outside labels or watermarks.

Screen inserts:
1. Hero — A Different Class Of Drive, BMW X5 and rental finder.
2. Fleet — Six vehicle cards, icon specifications, swatches and daily prices.
3. The VELAR Way — Interactive benefit pointers and supporting car image.
4. Getaway — Orange Porsche CTA banner.
5. Locations — Marina Bay, Orchard and Jewel Changi photographs.
6. Booking — Vehicle configuration, dates, optional coverage and price summary.

The working demo retains real source imagery and interactive front-end code. Mockup images are portfolio presentation assets.
